How publishing works.
This dashboard is a proof of concept — edits live only in this browser. To publish for everyone, hit Export schedule.json and commit the file to the repo (the data/ folder). That push triggers a Vercel redeploy and the new schedule goes live in ~30s. A Git-based CMS (Decap / Tina) can later automate this commit step so there's no manual download.
